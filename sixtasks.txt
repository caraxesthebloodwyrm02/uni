     coverage baseline.

     Implement mangrove/tests/apparat/test_accuracy.py to verify the exact
     mathematical and logical output of every handler.
     - Method: Use a fixed 2x2 input grid and assert that the resulting

     - Targets: normalize, scale, clamp, invert, and highlight handlers.
     - Verification: Direct equality check of GridCell objects (leveraging the
     frozen=True dataclass).

     2. Robustness & Safety: The "Negative Path" Matrix

     Implement mangrove/tests/apparat/test_robustness.py to exercise every error

     names.
     - Parameter Violations: Trigger Missing required parameter and Unexpected 
     parameters (length check).
     - Type Mismatches: Trigger Parameter validation error via incorrect types
     (e.g., string for float).
     - Chaos Testing: Dynamically register a chaos_handler that raises
     RuntimeError or AttributeError to verify the processor's safety wrapper
     converts them to ApparatValidationError.

     3. Structural Integrity: The "Diagnostic" Suite

     Implement mangrove/tests/apparat/test_diagnostics.py to catch subtle bugs
     that don't trigger exceptions.
     - Length Invariance: Verify that handlers (except filter) always return a

     mutated by handlers.

     [].
